Cybersecurity Labs I work on to prepare for an Enterprise SOC environment
  <h2> Step 1: Setting up the Ethernet cables on the WAN topology </h2> 
  <p align="center"> 
    I first used all the correct tools like fast ethernet port and computers and switches and routers to create this star topology.  I looked at the bottom and left menu in packet tracer and then clicked on Connections icon, i then selected the orange lightning bolt, once i selected the copper straight-through cable and selected an available interface i dragged the cable over to the switch click on it and select Fastethernet 0/2. I did this for every one pc and switch and router

  <h3> Step 2: Configuring the switches and Routers </h3> 
  <p align="center"> 
 I then went on the cli of the router and switch, enabled to privileged exec mod, then entered its global configuration mode, and then selected interface [name]. Once that was complete I entered the correct ip address [IP] and subnet mask that assigns logical network address to the router. The main router was stuck in ROMMON mode so i needed to reload the router manually to return it to normal command line.
